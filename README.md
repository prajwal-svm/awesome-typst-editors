# Awesome Typst Editors [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A friendly list of Typst editors and apps, and the people who build them.

Browse every editor, and leave a heart for the ones you like, at [prajwal-svm.github.io/awesome-typst-editors](https://prajwal-svm.github.io/awesome-typst-editors/).

This list includes editors that have been public for at least a month and have at least 50 stars on their code host. The site shows every editor that's been public for at least a month.

## Desktop

- [Hilbert](https://github.com/aburousan/hilbert-editor) - An offline scientific IDE for Typst, with live PDF preview and tools for maths and physics.
- [Katvan](https://github.com/IgKh/katvan) - A bare-bones editor for Typst files, with a bias for right-to-left editing.
- [Oleafly](https://github.com/Oleafly/Oleafly) - A desktop editor for Typst, LaTeX and Markdown.
- [Texpile](https://github.com/texpile/texpile) - An offline LaTeX and Typst editor with visual and source editing.
- [Typesetter](https://codeberg.org/haydn/typesetter) - A Typst editor for focused writing, made for GNOME.
- [TypstEdit](https://github.com/SuperMegaFort/TypstEdit) - A lightweight, native macOS editor for Typst.
- [Typstify](https://github.com/typstify/typstify) - A cross-platform Typst editor.
- [Typstwriter](https://github.com/Bzero/typstwriter) - An integrated editor for the Typst typesetting system.

## Web

- [Collabst](https://github.com/collabst/collabst) - A self-hosted collaborative workspace for Typst.
- [TeXlyre](https://github.com/TeXlyre/texlyre) - A local-first LaTeX and Typst web editor with real-time collaboration and offline support.
- [TINO](https://github.com/confirm/tino) - A collaborative, self-hosted editing platform around Typst.

## Mobile

- [InkPond](https://github.com/Lin0u0/InkPond) - A native iOS and iPadOS editor for Typst.

## Contributing
